# model-routing

実装・バグ修正・調査・レビュー・大量生成などの作業を、難易度と種類に応じて外部モデル(Codex / Antigravity / opencodex)へ委任するときの振り分けルールをまとめたスキルです。

## 使い方

- `SKILL.md` — スキル本体(フロントマター付き)。対応するエージェントのスキルフォルダに置いて使います。
- `skill.yaml` — Muse 用のスキル定義(SKILL.md と同じフォルダに置きます)。

## 概要

- 振り分け表: 作業の種類と難易度ごとに委任先モデルと呼び方(CLI)を定義
- 委任文の書き方: 背景・対象範囲・完了条件・返却形式を必ず含める
- 委任先ごとの注意: Sol / Neon・Hydrogen / Luna(レビュー) / Fable / 大量出力作業者
- 守ること: 公式CLIの利用、認証情報を渡さない、出力はテストか差分で確認する
